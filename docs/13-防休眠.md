# Kindle 防休眠（SSH 不断网）

排查/部署时 Kindle 一休眠 WiFi 就断，SSH 连不上、用户没法测。这里给「临时防休眠」脚本，用完恢复。

> 实测时间 **2026-11-07**。设备 Kindle Paperwhite 3。

## 1. 现象

- Kindle 静置几分钟后 ping 不通（`Destination host unreachable`），SSH 超时。
- 排查日志发现 `preventScreenSaver` 被重置为 0（允许屏保）。

## 2. 根因

- KOReader 的 `settings.reader.lua` 里有 `auto_standby_timeout_seconds=-1`、`auto_suspend_timeout_seconds=-1`，只代表 KOReader **不主动**休眠。
- 但 KOReader 每次启动会把 `com.lab126.powerd preventScreenSaver` 设回 0，Kindle 系统 powerd 的空闲屏保逻辑仍会触发休眠 → WiFi 断。
- 网卡省电（`wlan0/power/control=auto`）也会在空闲时切省电模式。

## 3. keepalive 脚本

写 `/tmp/keepalive.sh`：

```sh
#!/bin/sh
# keepalive: 阻止 Kindle 屏保休眠导致 WiFi 断网
echo on > /sys/class/net/wlan0/power/control 2>/dev/null
while true; do
    lipc-set-prop com.lab126.powerd preventScreenSaver 1 2>/dev/null
    sleep 30
done
```

启动：

```sh
chmod +x /tmp/keepalive.sh
nohup /tmp/keepalive.sh > /dev/null 2>&1 &
```

验证：

```sh
lipc-get-prop com.lab126.powerd preventScreenSaver   # 应回 1
cat /sys/class/net/wlan0/power/control                # 应回 on
ps -ef | grep keepalive | grep -v grep
```

## 4. 恢复休眠（用完必做）

```sh
# 杀 keepalive
pkill -f keepalive.sh
# 恢复网卡省电
echo auto > /sys/class/net/wlan0/power/control
# 恢复允许屏保
lipc-set-prop com.lab126.powerd preventScreenSaver 0
```

> 不恢复的话 Kindle 会一直亮屏不熄、耗电。长期方案是只在需要 SSH 排查时临时开 keepalive，日常关闭。

## 5. 注意

- keepalive 脚本是**临时**的（在 /tmp，重启即丢），不是常驻方案。
- KOReader 重启会重置 `preventScreenSaver=0`，keepalive 每 30 秒设一次，能持续顶住。
- 若 Kindle 已休眠断网，只能物理唤醒（按电源键），keepalive 无法「唤醒已休眠」的设备，只能「阻止进入休眠」。
