# 04 · 微信读书与阅读插件

KOReader 上的阅读插件全景。**微信读书为主线**，番茄/Legado/Leko 为补充。

## 四插件速查

| 插件 | 仓库 | 版本 | 入口 | 用途 |
|---|---|---|---|---|
| 微信读书 | finlater/weread.koplugin | v1.7.0 | 工具菜单 | 微信读书本体 |
| 番茄小说 | hesan1232/fanqie.koplugin | v2.16.36 | 工具菜单 | 番茄免费小说 |

## 微信读书（weread.koplugin）

- 仓库 finlater/weread.koplugin（Isword 的 fork 只发到 v1.6.1，其 `weread/lib/updater.lua:15` 硬编码上游 release 地址，装了也会被在线更新带回上游，**直接用上游 finlater**）。
- 要求 KOReader ≥ 2026.03。
- 登录前置：手机微信读书 App → 我 → 设置 → 微信读书 Skill → 获取 API Key → 插件内微信扫码登录。
- 开源版只读展示划线；写互动用 finlater 的闭源 WeReader。

## 番茄小说（fanqie.koplugin）

- 走官方 App reading 协议，**免书源**，直接能看番茄免费小说。
- 菜单 id `fanqie`（`main.lua:569` sorting_hint tools）。

## Legado（开源阅读）

- 连手机「阅读3.0」Web 服务，默认 `http://IP:1122`；reader3 服务版加 `/reader3`，轻阅读加 `/api/5`；验证 `http://IP:1122/test` 应显示 `web/test`。
- 菜单 id `Legado_main`（**大写 L**），插件默认 sorting_hint="search"（顶部搜索）；本机 `filemanager_menu_order.lua` 已把它归位进**工具菜单**。
- 升级到 v1.2.3 时要删旧版遗留模块 + 插件内 `patches/` + KOReader 级 `patches/2-legado_plugin_func.lua`。

### 本机连 NAS Reader3（不连手机）

本机不用手机版，改连 NAS 上的 Reader3 服务：

| 项 | 地址 |
|---|---|
| NAS Reader3（内网） | `http://192.168.0.117:4396`（Docker `changshengyu/reader:latest`，容器 8080 映射 4396） |
| Reader3 公网 | `https://reader3.ksoul.top`（CF 隧道 c43cf4ca，NAS cloudflared 常驻） |
| 书源（booksource.json） | `https://jlmon.ccwu.cc/booksource.json`（nginx `192.168.0.117:4397` 经 CF 发布） |

- 配置：插件内「手机APP WEB服务地址」填 `http://192.168.0.117:4396`（插件自动追加 `/reader3`）；默认值是 `http://127.0.0.1:1122`（`Backend.lua:689`）。
- 本机 `settings.reader.lua` 尚未写入 legado 键（仍是默认值），需在插件界面配置一次。

## Leko（纯本地）

- QuickJS 解析 Legado 兼容书源，**不需要手机**，自导书源。
- 入口 = 文件管理器顶栏 Leko 书架图标（`Leko/FileManagerTab.lua`，`id="leko_bookshelf"`，fallback_icon="book.opened"），不是工具菜单。
- 含 `Leko/native/liblekoqjs.so`（armhf 32 位）。

### 书源订阅（BookSourceSubscription，自造模块）

让 Leko 每天自动拉一次自有 Legado 书源 `https://jlmon.ccwu.cc/booksource.json`，全程在 Kindle 上跑：

- 源码：`packages/plugins/leko-subscription/BookSourceSubscription.lua`（184 行，模块 `BookSourceSubscription`）。
- 落位：拷到 `Leko/BookSourceSubscription.lua`（与 `Storage.lua` / `AsyncSourceImport.lua` 同级）。
- App.lua 接线：`App:init()` 里 `Storage:releaseSourceSettings()` 之后、`AsyncMaintenance` require 之前插两行：

```lua
local BookSourceSubscription = require("Leko/BookSourceSubscription")
BookSourceSubscription:start()
```

- 行为：KOReader 启动 120s 后首次刷新，之后每 24h 一次，失败 6h 重试。状态写 `settings.lua` 的 `["leko_book_source_subscription"]`（`last_source_count` / `last_success_at` / `next_run_at` / `failure_count`）。
- 关键参数：`backup=false`（跳过 `backupImportedSources` 快照，避免 `imports/` 每天累积 raw feed）、`return_summary_only=true`（`AsyncSourceImport` 硬编码，只计数不落 `imports/`）。
- 实测：451 源成功写入 `sources.lua`（2.36MB，`dofile` 计数 451 与服务器一致），阅读数据 books=6411 不变。

## 原生微信读书（Isword，非插件）

`kindle-weread-0.3.9-install.zip`（47 MB，AppID `tech.isword.weread.test`，**不依赖 KOReader**，越狱 + KUAL 即可）：

- 四目录合并复制到 USB 根：`weread/`(26.87 MB, 40 文件) + `fonts/`(55.28 MB，必须整带含 `noto/` 和 `.LICENSE`) + `documents/`(3 个 `.sh`) + `extensions/weread/`。
- 7 个 armhf **静态链接 ELF**（无 PT_DYNAMIC）：`weread/bin/kindlepw2/weread_ui` 9,635,232 / `script-runtime` 2,997,512 / `framework-session` 69,624 / `fb-session` 54,672 / `screen-refresh` 58,516 / `fsr-session` 52,648 / `device-info` 44,680；`kindlehf/` 是 arm64 套。
- `start.sh` 用 `if [ -e /lib/ld-linux-armhf.so.3 ]` 判定 kindlehf/kindlepw2（PW3 走 kindlepw2），再 `exec script-runtime <sha256> $0 "$@"`（完整性校验）。
- 升级后必须重新扫码登录；安全模式默认开启（整本下载按钮不可用，需进设置关）。
- 启动：KUAL → WeRead 三个按钮（Start WeRead / WeRead compatibility report / Restore launch state）。

## 统一菜单入口

四个插件都进 **工具（第 3 标签）**，顺序 `weread → fanqie → Legado_main → leko`。这是靠 `settings/reader_menu_order.lua` / `settings/filemanager_menu_order.lua` 里 `order.tools` 组开头 `table.insert` 实现的，详见 [06-菜单优化手册](06-菜单优化手册.md)。

## 插件安装通用

1. 所有 zip 在 PC 解压，把 `xxx.koplugin/` 整目录拷进 `H:\koreader\plugins\`。
2. **逐文件 Copy-Item**，别 robocopy 递归（MTP 会卡死，见 01）。
3. 拷完核对文件数，重启 KOReader。
4. 新版 KOReader（2026.07）有 `plugins_disable_external` 外部插件总开关（`frontend/pluginloader.lua:213`），若外部插件全不显示先查这个。
