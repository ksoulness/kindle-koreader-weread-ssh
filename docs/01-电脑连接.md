# 01 · 电脑连接

KPW3 通过 USB 连电脑，Windows 下映射为 **H:** 盘（FAT32，约 1 GB，MTP 传输）。

## 盘符与卷

- 卷标 `Kindle`，内部存储 1 GB（实测剩约 444 MB）。
- 所有文件操作都在这个卷上：`H:\koreader\`、`H:\extensions\`、`H:\documents\`、`H:\fonts\`、`H:\weread\`、`H:\system\`。
- 设备端路径对应：`H:\koreader` ↔ `/mnt/us/koreader`，`H:\extensions` ↔ `/mnt/us/extensions`。

## 连接与断开

- 插 USB 后 Kindle 弹出「USB 驱动模式」，点确认才会挂载出 H:。
- **弹出前必须先从 Windows 安全移除**，否则 FAT32 写缓存不落盘、目录损坏（尤其刚拷完大量小文件时）。
- 设备重连后若 H: 不出现：`Get-Disk` 看 Kindle Internal Storage 状态，必要时 `Disable-PnpDevice`/`Enable-PnpDevice` 重枚举 `USB\VID_1949&PID_0004\...`。

## 文件拷贝的三个坑

### 1. MTP 卷上 robocopy 递归拷小文件会卡死

实测把 weread 插件（40 个文件）用 `robocopy` 递归拷进 H:，卡在 35/40 文件不动。**MTP 层对递归+大量小文件极不友好，必须逐文件 `Copy-Item`**：

```powershell
Get-ChildItem "$src" -Recurse -File | ForEach-Object {
    $rel = $_.FullName.Substring($src.Length).TrimStart('\')
    $dst = Join-Path $dest $rel
    $null = New-Item -ItemType Directory -Force (Split-Path $dst)
    Copy-Item -LiteralPath $_.FullName -Destination $dst -Force
}
```

### 2. 设备 busybox 没有 unzip

KOReader 自带的 busybox 只有 `tar`/`dropbear`/`scp`/`luajit`，**没有 `unzip`**。所有 zip 解压都在 PC 侧做，解完再拷进设备。

### 3. 拷完要核对文件数

MTP 静默丢文件的概率不低，拷完关键目录（插件、fonts）务必核对条目数。以 weread 插件为例：源 91 文件，落地要逐个确认；fonts 55 MB 11 文件必须整带（含 `noto/` 和 `.LICENSE`）。

## 目录结构一览（越狱 + KUAL 后）

```
H:\
├── extensions\        # KUAL 扩展（koreader / weread / KOSSH / filebrowser / MRInstaller）
│   ├── koreader\      #   KOReader 启动按钮（menu.json + config.xml）
│   ├── weread\        #   原生微信读书启动按钮
│   └── KOSSH\         #   KOSSH（兜底 SSH）
├── koreader\          # KOReader 主程序 + plugins\ + settings\ + settings.reader.lua
├── documents\         # 微信读书*.sh（原生版启动脚本）
├── fonts\             # 原生微信读书字体（55 MB，必须整带）
├── weread\            # 原生微信读书 App（26.87 MB）
└── system\version.txt # 固件版本
```

## 验证连接成功

```powershell
Get-Volume -FileSystemLabel Kindle      # 或
Get-PSDrive H                           # H: 存在且可写
Get-Content H:\system\version.txt       # 固件版本号
```
