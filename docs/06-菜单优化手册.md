# 06 · 菜单优化手册

KOReader 顶部菜单的机制 + 四种常用操作 + 调出 SSH 的三条路。文件都在 `/mnt/us/koreader/settings/`。

## 机制速查

- **配置文件**：`settings/reader_menu_order.lua`（阅读器）+ `settings/filemanager_menu_order.lua`（文件管理器）。两个都要改，否则只改一个场景生效。
- **filemanager 顶部 5 标签**：`filemanager_settings / setting(齿轮) / tools / search / main`。
- **reader 顶部 7 标签**：`navi / typeset / setting(齿轮) / tools / search / filemanager / main`。
- **覆盖规则**（`frontend/ui/menusorter.lua:22 readMSSettings`）：`settings/<prefix>_menu_order.lua` 存在则 `dofile` 整体覆盖 factory 默认 order——你写的是「全量表」，不是增量。
- **隐藏**：`order["KOMenu:disabled"] = { "id1", "id2" }`，这些 id 从 item_table 移除。
- **第二页**：`more_tools` 组是「更多工具」第二页。
- **孤儿项**：菜单项无 sorting_hint 且不在 order 里 → 加 `NEW: ` 前缀塞进第一个标签。所以自定义插件的 id 必须显式写进 order，否则变「NEW: xxx」乱跑。

## 四种操作

### 1. 重排顶部标签顺序

编辑 `order["KOMenu:menu_buttons"]` 数组顺序即可（filemanager 例）：

```lua
order["KOMenu:menu_buttons"] = {
    "filemanager_settings",
    "setting",   -- 齿轮，第 2 个
    "tools",     -- 工具，第 3 个
    "search",    -- 搜索，第 4 个
    "main",
}
```

### 2. 重排组内顺序

组内列表顺序 = 显示顺序。把插件提到组开头：

```lua
order.tools = {
    "weread", "fanqie", "legado_main", "leko",  -- 四插件排最前
    -- ... 其余默认项
}
```

### 3. 隐藏某菜单项

```lua
order["KOMenu:disabled"] = {
    "newsdownloader", "wallabag",  -- 不想要的插件
}
```

### 4. 下沉到「更多工具」第二页

把 id 从 `tools` 组挪到 `more_tools` 组即可（`more_tools` 是第二页）。

## 调出 SSH 的三条路

当「齿轮 → 网络」里没有 SSH server，本质是 `plugins_disabled["SSH"]=true` 插件没加载。三种解法任选：

1. **界面点（推荐）**：工具 → 更多工具 → 插件管理 → 勾选启用 `SSH` → 重启 KOReader。
2. **删禁用项**：编辑 `settings.reader.lua`，删 `["SSH"] = true,`，重启 KOReader。
3. **菜单归位**：把 `"ssh"` 从 `network` 组挪到 `setting` 组顶层（让它直接出现在齿轮菜单，不再藏在网络子菜单里）：

```lua
order.setting = {
    "network", "ssh",  -- ssh 直接浮到齿轮顶层
    -- ...
}
```

> ⚠️ 方法 2 改 `settings.reader.lua` 前**必须先退出 KOReader**，否则运行中的内存值会在退出时回写覆盖你的修改。

## 实测结论（重要）

- SSH 菜单项在**默认 factory order** 里就列在 `network` 组末尾（分隔线之后），所以只要插件没被禁用，它**天然就在「齿轮 → 网络 → SSH server」**，不需要任何 menu_order 改动。
- 一旦「网络里没有 ssh」，**优先怀疑插件被禁用**（查 `plugins_disabled`），而不是菜单排序问题。排序改动只能「挪位置」，救不了「不加载」。
